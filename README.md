# 依依灵球 YiYi Ball

依依灵球是一款 Windows 桌面 AI 语音助手。一颗悬浮球常驻屏幕边缘：喊一声「小依小依」就能唤醒对话，它听着、想着、答着，还能替你动手——打开应用、写入文字、搜文件、操控浏览器。屏幕上选中一段文字，辅助球随即出现在旁边，点一下就是译文。

语音唤醒、语音识别、语音合成全部内置在本地模型里，克隆仓库、编译完成，这台机器上的完整功能就绪，不需要再下载任何模型或运行时。界面使用 WinForms（.NET 8）构建，不依赖 Electron。

## 喊一声「小依小依」，说完它就去做

* **免手唤醒**：说「小依小依」唤醒对话，也可以双击主球进入，或长按 ≥ 0.5 秒直接说话；贴边吸附的球会自动滑出，白条提示语跟在球下。
* **听得见"小依小依"**：支持完整唤醒词「小依小依」以及「hey / hi，小依」；不再接受「小依」「依依」等短词，避免日常说话被误唤醒。由本地 KWS 模型（sherpa-onnx zipformer，中英双语）检测，离线运行，语音不上传。
* **全程有回应**：倾听、识别、思考、回复、执行五个状态在球内实时变色——绿色在听、紫色播报、蓝色执行；配落地提示音。
* **说完就干活**：回复不是终点。它接着进入执行阶段，调用本地工具箱把事情做完。

## 会动手，不只是会聊天

| 你说                     | 它做                                        |
| ---------------------- | ----------------------------------------- |
| "打开计算器" / "开一下微信"      | open_app：App Paths + 开始菜单统一候选评分，支持别名       |
| "把这段写进去" / "第三行改成……"    | insert_text / edit_text：光标处写入与改写           |
| "帮我找一下那个报销表"            | find_file：文件搜索，结果可直接打开                     |
| "搜一下最近的发布会时间"           | web_search / open_url：联网检索与跳转              |
| "把网页往下翻，点那个登录按钮"         | browser_control / screen_click：受控 Chromium 页面理解与点击 |
| "调低音量" / "连一下 Wi-Fi"    | media_control / system_control：系统级控制       |

* **技能会沉淀**：一次多步任务做完，说一句"记住这个流程"，它把真实执行过的工具调用序列存成技能，下次一句话直接回放。
* **浏览器是真浏览器**：内置 Playwright 受控 Chromium（随安装包携带，免首次下载），页面理解用文本快照，不截屏猜元素。

## 选中哪里，翻译哪里

* **辅助球即点即译**：选中文字后，一颗白色小球出现在选区旁，单击翻译，超时自动淡出，不打扰。划词自动捕捉可在设置中关闭；检测到真实 Ctrl/Shift/Alt/Win 操作时会跳过自动取词，避免复制粘贴被干扰。
* **截图翻译**：单击主球进入全屏框选，选区内恢复原亮度，松手即截即译；Esc / 右键取消。
* **多屏支持**：高 DPI（PerMonitorV2）与虚拟屏适配。

## 记得你说过的事

* **长期记忆**：对话中说"记一下……"就入库；检索按语义相似度召回，越用越懂你。
* **资料知识库**：把文件夹交给它（txt / md / pdf / docx），自动分块、向量化、增量扫描；回答时引用你的资料。
* **本地存储**：记忆、知识库、技能、历史都在本机 SQLite 单文件里（`data/memory.db`），不走任何第三方存储。

| 保存什么     | 在哪里                              |
| -------- | -------------------------------- |
| 长期记忆 / 技能 | `data/memory.db`（本机 SQLite）       |
| 翻译与对话历史   | 本机历史存储，可随时查看                      |
| 配置与 API Key | `config.json`（仅本机）               |
| 崩溃日志      | `data/crash.log`（仅本机排查用）          |

## v1.1.1 更新说明

* **复制粘贴稳定性修复**：划词自动取词会避让真实 Ctrl/Alt/Win 操作和剪贴板变化，避免 Ctrl 键状态残留、复制失效或 Ctrl+V 只输入 V；设置 > 翻译 > 划词行为可关闭自动捕捉。
* **剪贴板保护**：自动取词只恢复本次捕获产生的内容，不再覆盖用户同时复制的新文本。
* **日常应用语义操作**：支持打开并置前应用、应用内搜索、打开结果、播放、查找联系人和发送消息；覆盖微信、QQ、钉钉、飞书、抖音、快手、哔哩哔哩、网易云音乐、QQ音乐、腾讯视频、爱奇艺、优酷、芒果TV、原神等常用应用。
* **搜索与播放严格区分**：说“搜索/查一下”只搜索；说“打开/点开第一条”才打开结果；明确说“播放”才播放，避免误操作。
* **客户端优先、网页兜底**：本机已安装对应客户端时优先在客户端内操作，未安装时自动回退到网页版。
* **客户端启动等待**：客户端窗口出现后会继续等待界面渲染完成再搜索，避免启动帧或白屏期间校验失败；确实无法定位搜索框时仍保留媒体类网页兜底。
* **聊天操作防误关**：微信/QQ 等聊天窗口不再盲按 Esc，也不再重复打开同一联系人；“当前会话”直接用现有聊天输入框；非明确关闭指令不会关闭窗口、发送 Alt+F4 或结束进程。
* **聊天渲染修复**：对话区支持代码块、表格、标题、引用和分隔线；代码块带语言标识、复制和下载，窄窗口下表格可横向滚动。
* **语音播报修复**：TTS 服务改为并发处理；Edge 在线合成增加 8 秒超时，失败自动切换本地 ZipVoice；修复部分网络环境下响应体被截断导致的长时间等待和无声问题。
* **唤醒词收紧**：只保留完整唤醒词「小依小依」「hey 小依」「hi 小依」，并提高 KWS 判定阈值，避免「依依/一一」等短音误触发。

## 下载安装

前往 **[Releases 发布页](../../releases)**，选择：

| 下载文件                        | 使用方式                                                     |
| --------------------------- | -------------------------------------------------------- |
| YiYiBall-Setup-1.1.1.exe    | **推荐**。双击安装，内置全部模型、运行时与 Chromium；首次运行有安装协议确认             |
| 源码仓库（本页）                     | 克隆后编译，模型已随仓库分发，编译即完整可用（见下节）                              |

* **系统**：Windows 10 / 11 x64。
* **依赖**：无。安装包与源码仓库均自带 .NET 运行时（自包含发布）、推理模型与浏览器内核，不需要另装 .NET、Python 或模型文件。
* **首次启动**：弹出引导窗，确认服务地址并填入你的 API Key 即可（大模型对话 / 识别走你配置的云端服务）。
* **未签名提示**：当前程序未做商业代码签名，Windows 可能提示未知发布者，请核对仓库来源。

## 从源码构建

需要 .NET 8 SDK（Windows x64）。

```powershell
git clone https://github.com/HanFeng-wang/YiYiBall.git YiYiBall
cd YiYiBall
dotnet publish YiYiBall.csproj -c Release -r win-x64 --self-contained true -o publish
.\publish\YiYiBall.exe
```

开发调试直接 `dotnet build -c Release` 后运行 `bin\Release\net8.0-windows\YiYiBall.exe`。

* 需要安装 [Git LFS](https://git-lfs.com)（Git for Windows 自带）：离线 TTS 主模型（约 119 MB）通过 LFS 分发，克隆时自动拉取。
* 运行时必需的 int8 模型已随仓库分发（唤醒 KWS、ZipVoice 离线 TTS、vocoder、英文词表），克隆后无需任何额外下载步骤。
* 开发用 fp32 模型、测试音频与文档不在仓库内，不影响编译与运行。

## 数据与隐私

* **唤醒与录音**：「小依小依」等唤醒词的检测完全在本机模型上运行；只有你主动进入对话后，音频才会发送给你配置的语音识别服务。
* **语音合成**：优先使用在线语音，失败时自动切换到内置的离线克隆模型，全程可在本机完成。
* **记忆与知识库**：全部保存在本机 `data/` 目录，程序不内置任何上传后台。
* **API Key**：保存在本机 `config.json`，请不要把它提交到仓库或贴到 Issue。
* **声音素材合规**：音色克隆参考音频与商用 TTS 音色样音未经授权不随源码分发，见 LICENSE 第二条。
